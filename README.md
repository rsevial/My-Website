# My Website

This repository contains Python and HTML files for my website. The website contains my profile, contact information, and programming work. It has three programming functions: to uppercase a string, calculate the area of a circle, and get the area of a triangle.

### Needed to Create the Website

- Python

- Flask

### File Summary

> app.py
- Python script that defines a web application using the Flask framework

> static
- Special directory folder to store static files such as images that were used to create the website.

> templates
- A folder that contains all the HTML files that were used in the project
